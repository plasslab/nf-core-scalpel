# scalpelR reference

Functions of the R package [scalpelR](https://github.com/Franzx7/scalpelR) (version 0.3.0) for the downstream analysis of the SCALPEL results.

| Function | Description |
| --- | --- |
| [`CoveragePlot`](CoveragePlot.md) | Read Coverage of a Gene per Group of Cells |
| [`FindIsoforms`](FindIsoforms.md) | Differential Isoform Usage Between Groups of Cells |
| [`plotExpression`](plotExpression.md) | Plot Relative Isoform or Feature Expression Across Groups |
| [`plotShiftHeatmap`](plotShiftHeatmap.md) | Heatmap of the 3' UTR Shifts between Groups of Cells or along a Trajectory |
| [`plotUsage`](plotUsage.md) | Isoform Usage per Group of Cells |
| [`subsetBAM`](subsetBAM.md) | Subset BAM File by Barcodes |
| [`weightedUTR_cell`](weightedUTR_cell.md) | Calculate Weighted UTR Length per Cell |
