# CoveragePlot

Read Coverage of a Gene per Group of Cells

```{raw} html



<h3>Description</h3>

<p>Plots the read coverage of a gene for each group of cells (e.g. cell types) from the BAM files of the
reads used by SCALPEL (<code>&lt;outdir&gt;/filtered_bams/&lt;sample&gt;_filtered.bam</code>), with the structure of its
isoforms. The reads of each group are selected from the BAM files with the cell barcodes of the Seurat
object (no intermediate BAM file), and the coverage is normalized by the number of cells of the group.
</p>


<h3>Usage</h3>

<pre><code class='language-R'>CoveragePlot(
  seurat_obj,
  bamfiles,
  gene_in,
  genome_gr,
  group_by,
  features = NULL,
  groups = NULL,
  sample_by = "orig.ident",
  barcode_col = "Barcodes",
  tag = "CB",
  stranded = TRUE,
  distZOOM = NULL,
  extend = 1000,
  samtools.bin = "samtools",
  colors = NULL
)
</code></pre>


<h3>Arguments</h3>

<table>
<tr><td><code id="seurat_obj">seurat_obj</code></td>
<td>
<p>iDGE Seurat object generated by SCALPEL (or any Seurat object whose cells are the cells
of the BAM files).</p>
</td></tr>
<tr><td><code id="bamfiles">bamfiles</code></td>
<td>
<p>Named vector of BAM files, names = sample names (<code>sample_by</code> values), e.g.
<code>c(SRR6129050 = "results/filtered_bams/SRR6129050_filtered.bam", ...)</code>.</p>
</td></tr>
<tr><td><code id="gene_in">gene_in</code></td>
<td>
<p>Gene name.</p>
</td></tr>
<tr><td><code id="genome_gr">genome_gr</code></td>
<td>
<p>GTF <code>GRanges</code> (e.g. <code>rtracklayer::import("annotation.gtf.gz")</code>).</p>
</td></tr>
<tr><td><code id="group_by">group_by</code></td>
<td>
<p>Metadata column with the groups of cells (one coverage track per group).</p>
</td></tr>
<tr><td><code id="features">features</code></td>
<td>
<p>Optional transcript names to draw. Default: the isoforms of the gene in the Seurat
object (SCALPEL isoforms), or all transcripts of the gene if none.</p>
</td></tr>
<tr><td><code id="groups">groups</code></td>
<td>
<p>Optional subset / order of the groups to plot.</p>
</td></tr>
<tr><td><code id="sample_by">sample_by</code></td>
<td>
<p>Metadata column with the sample of each cell (names of <code>bamfiles</code>). Default
<code>"orig.ident"</code>.</p>
</td></tr>
<tr><td><code id="barcode_col">barcode_col</code></td>
<td>
<p>Metadata column with the cell barcode as in the BAM tag. Default <code>"Barcodes"</code>.</p>
</td></tr>
<tr><td><code id="tag">tag</code></td>
<td>
<p>BAM tag of the cell barcode: <code>"CB"</code> (10x, STARsolo) or <code>"XC"</code> (Drop-seq).</p>
</td></tr>
<tr><td><code id="stranded">stranded</code></td>
<td>
<p>Keep only the reads on the strand of the gene (3'-tagged libraries). Default <code>TRUE</code>.</p>
</td></tr>
<tr><td><code id="distZOOM">distZOOM</code></td>
<td>
<p>Optional. Plot only the last <code>distZOOM</code> nt of the gene (3' end side).</p>
</td></tr>
<tr><td><code id="extend">extend</code></td>
<td>
<p>Number of nt plotted beyond the 3' end of the gene (reads downstream of the annotation).
Default 1000.</p>
</td></tr>
<tr><td><code id="samtools.bin">samtools.bin</code></td>
<td>
<p>Path to <code>samtools</code>. Default <code>"samtools"</code>.</p>
</td></tr>
<tr><td><code id="colors">colors</code></td>
<td>
<p>Optional colors of the groups (named by group).</p>
</td></tr>
</table>


<h3>Value</h3>

<p>A <code>patchwork</code> / <code>ggplot</code> object: coverage per group (reads per 1000 cells) above the
isoform structures (thick: CDS, thin: UTR).
</p>


<h3>Examples</h3>

<pre><code class='language-R'>## Not run: 
gtf = rtracklayer::import("gencode.vM21.annotation.gtf.gz")
CoveragePlot(idge, bamfiles = c(SRR6129050 = "results/filtered_bams/SRR6129050_filtered.bam",
                                SRR6129051 = "results/filtered_bams/SRR6129051_filtered.bam"),
             gene_in = "Reep1", genome_gr = gtf, group_by = "celltype", distZOOM = 4000)

## End(Not run)

</code></pre>

</main>

```
