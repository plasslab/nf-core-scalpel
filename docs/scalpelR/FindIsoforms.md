# FindIsoforms

Differential Isoform Usage Between Groups of Cells

```{raw} html



<h3>Description</h3>

<p>Tests, for each gene, whether the usage of its isoforms (fraction of the gene counts) differs between
groups of cells of an iDGE Seurat object generated by SCALPEL, with the same method as the
nf-core/scalpel pipeline (<code>differential/DIU_table.csv</code>).
</p>


<h3>Usage</h3>

<pre><code class='language-R'>FindIsoforms(
  seurat_obj,
  group_by,
  sample_by = "orig.ident",
  assay = "RNA",
  isoform_annotation = NULL,
  test = "chisq",
  threshold_pval = 0.05,
  threshold_abund = 0.05,
  threshold_var = 0.1,
  n_perm = 10000,
  cores = 1,
  seed = 1,
  extended = FALSE
)
</code></pre>


<h3>Arguments</h3>

<table>
<tr><td><code id="seurat_obj">seurat_obj</code></td>
<td>
<p>Seurat object with isoform counts (features <code>gene***isoform</code>), e.g.
<code>&lt;outdir&gt;/differential/iDGE_seurat.RDS</code>. Counts split in several layers (one per sample) are joined.</p>
</td></tr>
<tr><td><code id="group_by">group_by</code></td>
<td>
<p>Metadata column with the groups of cells to compare (2 groups: group1 vs group2;
more than 2 groups: each group vs the rest).</p>
</td></tr>
<tr><td><code id="sample_by">sample_by</code></td>
<td>
<p>Metadata column with the sample of each cell (default <code>"orig.ident"</code>), used to
permute the cells within samples (<code>test = "permutation"</code>) and to assess the replication of the
changes in each sample. <code>NULL</code>: not used. Ignored if equal to <code>group_by</code>.</p>
</td></tr>
<tr><td><code id="assay">assay</code></td>
<td>
<p>Seurat assay. Default <code>"RNA"</code>.</p>
</td></tr>
<tr><td><code id="isoform_annotation">isoform_annotation</code></td>
<td>
<p>Isoform 3' ends: the SCALPEL isoform annotation (directory
<code>&lt;outdir&gt;/isoform</code> or <code>*.annots.gz</code> files, recommended) or a GTF <code>GRanges</code>
(e.g. <code>rtracklayer::import("annotation.gtf")</code>). <code>NULL</code>: no event type / direction.</p>
</td></tr>
<tr><td><code id="test">test</code></td>
<td>
<p><code>"chisq"</code> (X2 test on the counts aggregated per group, original SCALPEL) or
<code>"permutation"</code> (same X2 statistic, p-value from permutations of the cells between the compared
groups, within samples: accounts for the cell-to-cell variability of the isoform usage).</p>
</td></tr>
<tr><td><code id="threshold_pval">threshold_pval</code></td>
<td>
<p>Adjusted p-value threshold. Default 0.05.</p>
</td></tr>
<tr><td><code id="threshold_abund">threshold_abund</code></td>
<td>
<p>Isoforms below this fraction of the gene counts in both groups are not tested
(<code>thr.abund</code>). Default 0.05.</p>
</td></tr>
<tr><td><code id="threshold_var">threshold_var</code></td>
<td>
<p>Minimal isoform usage change between groups (<code>thr.var</code>, <code>max_delta_PU</code>).
Default 0.1.</p>
</td></tr>
<tr><td><code id="n_perm">n_perm</code></td>
<td>
<p>Maximal number of permutations per gene (<code>test = "permutation"</code>). Default 10000.</p>
</td></tr>
<tr><td><code id="cores">cores</code></td>
<td>
<p>Number of cores. Default 1.</p>
</td></tr>
<tr><td><code id="seed">seed</code></td>
<td>
<p>Random seed (permutations). Default 1.</p>
</td></tr>
<tr><td><code id="extended">extended</code></td>
<td>
<p><code>FALSE</code> (default): isoforms of the genes with a differential isoform usage only
(adjusted p-value &lt; <code>threshold_pval</code>, <code>max_delta_PU &gt;= threshold_var</code>, change not
contradicted between samples). <code>TRUE</code>: all tested genes.</p>
</td></tr>
</table>


<h3>Details</h3>

<p>Isoform counts are aggregated per group; isoforms below <code>threshold_abund</code> in both groups are not
tested, and genes are tested when at least 2 isoforms remain and all expected counts are &gt;= 5. The
p-values are adjusted (Benjamini-Hochberg) once per gene and comparison.
</p>
<p>Each gene is classified as <code>tandem_3UTR</code> (the tested isoforms share their terminal exon: alternative
polyadenylation in the same last exon) or <code>alternative_terminal_exon</code>. For tandem events,
<code>delta_3end</code> is the change of the weighted 3' UTR length of group1 vs group2 (nt) and
<code>direction</code> is <code>shortening</code> or <code>lengthening</code>.
</p>
<p>With <code>sample_by</code>, the change of the most changing isoform of each gene is measured in each sample
(samples with &gt;= 20 UMIs of the gene in both groups): <code>replicated</code> is TRUE when it has the same sign
and at least half of <code>threshold_var</code> in every evaluable sample (NA if fewer than 2 samples).
</p>


<h3>Value</h3>

<p>A <code>data.table</code> with one row per isoform and comparison: gene and isoform, comparison
(<code>comparison</code>, <code>group1</code>, <code>group2</code>), <code>event_type</code>, <code>direction</code>,
<code>delta_3end</code>, isoform counts (<code>counts.group1/2</code>), usage (<code>PU.group1/2</code>) and change
(<code>delta_PU</code>), gene <code>p.value.adjusted</code>, <code>p.value</code>, <code>statistic</code>,
<code>max_delta_PU</code>, replication (<code>replicated</code>, <code>delta_PU_by_sample</code>, ...), dominant
isoforms, 3' ends and filters, as the pipeline <code>DIU_table.csv</code>.
</p>


<h3>Examples</h3>

<pre><code class='language-R'>## Not run: 
idge = readRDS("results/differential/iDGE_seurat.RDS")
idge$celltype = ...
diu = FindIsoforms(idge, group_by = "celltype", isoform_annotation = "results/isoform",
                   test = "permutation", cores = 8)

## End(Not run)

</code></pre>

</main>
```
