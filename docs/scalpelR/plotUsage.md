# plotUsage

Isoform Usage per Group of Cells

```{raw} html



<h3>Description</h3>

<p>Plots the usage of the isoforms of a gene (fraction of the gene counts) in each group of cells, as
tested by <code>FindIsoforms</code>, optionally in each sample (replication of the changes).
</p>


<h3>Usage</h3>

<pre><code class='language-R'>plotUsage(
  seurat_obj,
  gene_in,
  group_by,
  sample_by = NULL,
  groups = NULL,
  isoform_annotation = NULL,
  min_usage = 0.05,
  assay = "RNA"
)
</code></pre>


<h3>Arguments</h3>

<table>
<tr><td><code id="seurat_obj">seurat_obj</code></td>
<td>
<p>iDGE Seurat object generated by SCALPEL (features <code>gene***isoform</code>).</p>
</td></tr>
<tr><td><code id="gene_in">gene_in</code></td>
<td>
<p>Gene name.</p>
</td></tr>
<tr><td><code id="group_by">group_by</code></td>
<td>
<p>Metadata column with the groups of cells.</p>
</td></tr>
<tr><td><code id="sample_by">sample_by</code></td>
<td>
<p>Optional metadata column with the sample of each cell: usage in each sample shown as points.</p>
</td></tr>
<tr><td><code id="groups">groups</code></td>
<td>
<p>Optional subset / order of the groups.</p>
</td></tr>
<tr><td><code id="isoform_annotation">isoform_annotation</code></td>
<td>
<p>Optional SCALPEL isoform annotation (directory <code>&lt;outdir&gt;/isoform</code> or
<code>*.annots.gz</code> files) or GTF <code>GRanges</code>: isoforms ordered from the most proximal to the most
distal 3' end.</p>
</td></tr>
<tr><td><code id="min_usage">min_usage</code></td>
<td>
<p>Isoforms with a usage below this value in all the groups are merged in <code>"other"</code>. Default 0.05.</p>
</td></tr>
<tr><td><code id="assay">assay</code></td>
<td>
<p>Seurat assay. Default <code>"RNA"</code>.</p>
</td></tr>
</table>


<h3>Value</h3>

<p>A ggplot object: one bar per isoform and group (usage of all the cells of the group), points: usage in
each sample, number of gene UMIs of each group in the legend.
</p>


<h3>Examples</h3>

<pre><code class='language-R'>## Not run: 
plotUsage(idge, gene_in = "Reep1", group_by = "celltype", sample_by = "orig.ident",
          isoform_annotation = "results/isoform")

## End(Not run)

</code></pre>

</main>

```
