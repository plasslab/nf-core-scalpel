# plotShiftHeatmap

Heatmap of the 3' UTR Shifts between Groups of Cells or along a Trajectory

```{raw} html



<h3>Description</h3>

<p>Global view of the alternative polyadenylation: for each gene, the relative 3' UTR length (usage of the isoforms
weighted by their 3' UTR length) in each group of cells (and sample), or in bins of cells ordered along a
trajectory (pseudotime), centered on the gene mean. Blue: 3' UTR shorter than the gene mean, red: longer.
</p>


<h3>Usage</h3>

<pre><code class='language-R'>plotShiftHeatmap(
  seurat_obj,
  annotation_gr,
  group_by = NULL,
  sample_by = NULL,
  groups = NULL,
  order_by = NULL,
  n_bins = 30,
  genes = NULL,
  n_genes = 100,
  min_umis = 20,
  scale = TRUE,
  n_clusters = NULL,
  border = "black",
  show_genes = NULL,
  assay = "RNA"
)
</code></pre>


<h3>Arguments</h3>

<table>
<tr><td><code id="seurat_obj">seurat_obj</code></td>
<td>
<p>iDGE Seurat object generated by SCALPEL (features <code>gene***isoform</code>).</p>
</td></tr>
<tr><td><code id="annotation_gr">annotation_gr</code></td>
<td>
<p>GTF <code>GRanges</code> (e.g. <code>rtracklayer::import("annotation.gtf.gz")</code>): 3' UTR length of
the isoforms (UTR downstream of the CDS).</p>
</td></tr>
<tr><td><code id="group_by">group_by</code></td>
<td>
<p>Metadata column with the groups of cells (one column per group). With <code>order_by</code>, groups
shown in an annotation bar above the bins.</p>
</td></tr>
<tr><td><code id="sample_by">sample_by</code></td>
<td>
<p>Optional metadata column with the sample of each cell: one column per group and sample
(replication of the shifts). Ignored with <code>order_by</code>.</p>
</td></tr>
<tr><td><code id="groups">groups</code></td>
<td>
<p>Optional subset / order of the groups.</p>
</td></tr>
<tr><td><code id="order_by">order_by</code></td>
<td>
<p>Optional numeric metadata column (e.g. pseudotime): cells ordered by this value and pooled in
<code>n_bins</code> bins of the same number of cells (one column per bin).</p>
</td></tr>
<tr><td><code id="n_bins">n_bins</code></td>
<td>
<p>Number of bins of cells with <code>order_by</code>. Default 30.</p>
</td></tr>
<tr><td><code id="genes">genes</code></td>
<td>
<p>Optional genes: vector of gene names, or the table of <code>FindIsoforms</code> (genes with a tandem 3' UTR
event). Default: all the genes with isoforms of different 3' UTR lengths.</p>
</td></tr>
<tr><td><code id="n_genes">n_genes</code></td>
<td>
<p>Maximum number of genes shown: genes with the highest variation of their relative 3' UTR length
between the columns. Default 100.</p>
</td></tr>
<tr><td><code id="min_umis">min_umis</code></td>
<td>
<p>Minimum number of gene UMIs in a column (fewer: no value, gray). Default 20.</p>
</td></tr>
<tr><td><code id="scale">scale</code></td>
<td>
<p>If <code>TRUE</code> (default), relative 3' UTR lengths scaled per gene (z-score, capped at +/- 2);
otherwise centered on the gene mean.</p>
</td></tr>
<tr><td><code id="n_clusters">n_clusters</code></td>
<td>
<p>Optional number of clusters of genes (hierarchical clustering of the values): genes split in
blocks (e.g. early / late shortening, lengthening), cluster of each gene in <code>attr(p, "shift")</code>.</p>
</td></tr>
<tr><td><code id="border">border</code></td>
<td>
<p>Color of the tile borders (<code>NA</code>: none). Default <code>"black"</code>.</p>
</td></tr>
<tr><td><code id="show_genes">show_genes</code></td>
<td>
<p>Show the gene names (default: if 60 genes or less).</p>
</td></tr>
<tr><td><code id="assay">assay</code></td>
<td>
<p>Seurat assay. Default <code>"RNA"</code>.</p>
</td></tr>
</table>


<h3>Details</h3>

<p>The relative 3' UTR length of a gene in a column is the weighted 3' UTR length of its isoforms (counts of the cells
of the column) rescaled between its shortest (0) and longest (1) isoform 3' UTR. Isoforms without CDS are not
used. Genes are clustered (groups) or ordered by the bin of their longest 3' UTR (<code>order_by</code>). The table of
values is available in <code>attr(p, "shift")</code>.
</p>


<h3>Value</h3>

<p>A ggplot (patchwork with <code>order_by</code> and <code>group_by</code>) object.
</p>

plotShiftHeatmap(idge, annotation_gr = gtf, group_by = "celltype", order_by = "pseudotime", genes = diu.table)
```
